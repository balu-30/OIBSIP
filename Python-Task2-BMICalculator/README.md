# BMI Calculator
A simple Python command-line application that calculates a user's Body Mass Index (BMI) based on their weight and height and classifies the result into standard BMI categories.

## Features
- Accepts weight in kilograms (kg)
- Accepts height in meters (m)
- Calculates BMI
- Displays BMI rounded to 2 decimal places
- Classifies BMI as:
  - Underweight
  - NormalWeight
  - Overweight
  - Obesity
- Validates numeric input
- Rejects zero and negative values
- Displays helpful error messages

## BMI Formula
BMI is calculated using:
BMI = Weight (kg) / Height² (m²)

## BMI Categories
- Underweight: Less than 18.5
- Healthy weight: 18.5 to 24.9
- Overweight: 25.0 to 29.9
- Obesity: 30.0 or higher
